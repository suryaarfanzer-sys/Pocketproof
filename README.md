# PocketProof — Android MVP starter

PocketProof is a privacy-first warranty and valuables tracker starter project.

## Important status
This is a **starter source project**, not a finished or store-ready Android app. It has not been built or tested on a physical device, and does not include Google Play Billing, a production reminder scheduler, automated tests, or store compliance assets. Those require implementation and testing before sale.

## Current scope
- Add, edit, and delete items
- Track item name, brand, serial number, purchase date, warranty expiry, price, notes
- Search saved items
- Local browser storage (this starter runs as a responsive web app)
- English interface, mobile-first layout

## Run it on your phone
1. Open `index.html` in a modern browser, or upload this folder to a static web host.
2. Data is stored in that browser on that device. Clearing browser data can erase it.
3. For an Android app, package this web app with a trusted wrapper such as Capacitor in a cloud development environment, then build and test an APK/AAB.

## Before commercial release
- Add robust local database and export/import backup
- Implement and test warranty notifications
- Add Google Play Billing for one-time premium unlock (do not use external payment to unlock digital features in the Play Store app unless policy explicitly permits it)
- Implement restore purchases and purchase validation
- Add privacy policy, Data safety disclosures, support contact, store listing, screenshots, icon, and content rating
- Test on multiple Android versions and screen sizes
- Meet current Google Play target API and developer account requirements
- Review intellectual property, security, accessibility, and consumer laws for target markets

No sales, downloads, or revenue are guaranteed.
